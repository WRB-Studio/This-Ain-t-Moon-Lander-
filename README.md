# This-Ain-t-Moon-Lander-
Land on a planet. Manage gravity. Unlock ships. That’s it. Nothing else to see here. This is absolutely not a Moon Lander game. 🚫🌕

## GPT Web Development

ChatGPT Web development in this repository must follow [GPTWEB_RULES.md](GPTWEB_RULES.md).

- GPT Web integration branch: `gptweb/main`
- GPT Web never writes directly to `main`
- Features/fixes use dedicated `gptweb/feature-*` or `gptweb/fix-*` branches and merge back into `gptweb/main`
