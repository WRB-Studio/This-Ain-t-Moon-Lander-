# Kompaktere waagerechte Seitenansichten

Sechs neue Varianten der ursprünglichen Seitenansichten: Cockpit rechts, Antrieb links, Landefüße unten. Rümpfe und Frachtmodule wurden kompakter angelegt, während rollenbezogene Ausstattung und Schwarz-Weiß-Konturen erhalten bleiben. Der Scout bleibt schlank, der Frachter länger, Schlepper und Rettungsschiff kräftiger.

Bildreihenfolge: Courier, Scout, CargoTug (Schlepper), Freighter (Frachter), Rescue (Rettungsschiff), Maintenance (Wartungsschiff).

Erstellt mit dem eingebauten Imagegen-Tool. Die genauen Prompts stehen neben den PNGs. Grafikvorlagen auf schwarzem Hintergrund, noch nicht in die Testszene eingebaut. Alle vorherigen Varianten bleiben zum Vergleich erhalten.
